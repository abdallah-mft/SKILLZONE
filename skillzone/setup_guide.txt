===========================================
🚀 SKILLZONE BACKEND SETUP GUIDE 🚀
===========================================

1️⃣ VIRTUAL ENVIRONMENT SETUP
-------------------------------------------
# Create virtual environment
python -m venv venv

# Activate virtual environment
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate

2️⃣ REQUIRED PACKAGES
-------------------------------------------
# Core packages
pip install django
pip install djangorestframework
pip install djangorestframework-simplejwt
pip install django-cors-headers
pip install firebase-admin
pip install django-cache-memoize
pip install python-dotenv
pip install dj-database-url
pip install whitenoise
pip install redis

# Create requirements.txt
pip freeze > requirements.txt

# Install from requirements.txt (for other developers)
pip install -r requirements.txt

3️⃣ PROJECT SETUP COMMANDS
-------------------------------------------
# Create Django project
django-admin startproject skillzone

# Create apps
python manage.py startapp users
python manage.py startapp courses
python manage.py startapp quizzes
python manage.py startapp achievements

# Database setup
python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser

4️⃣ ENVIRONMENT SETUP
-------------------------------------------
# Create .env file (copy from .env.example)
DEBUG=True
SECRET_KEY=your-secret-key-here
ALLOWED_HOSTS=localhost,127.0.0.1
DATABASE_URL=sqlite:///db.sqlite3
REDIS_URL=redis://127.0.0.1:6379/1

5️⃣ FLUTTER FRONTEND SETUP
-------------------------------------------
1. Install Flutter SDK
2. Configure Android Studio/VS Code
3. Install required Flutter packages:
   ```yaml
   dependencies:
     flutter:
       sdk: flutter
     http: ^1.1.0
     shared_preferences: ^2.2.0
     provider: ^6.0.5
     firebase_messaging: ^14.6.5
     flutter_secure_storage: ^8.0.0
   ```

6️⃣ CORS & JWT CONFIGURATION
-------------------------------------------
# Add to settings.py
INSTALLED_APPS = [
    ...
    'rest_framework',
    'rest_framework_simplejwt.token_blacklist',
    'corsheaders',
]

MIDDLEWARE = [
    'corsheaders.middleware.CorsMiddleware',
    ...
]

# CORS Settings
CORS_ALLOWED_ORIGINS = [
    "http://localhost:8000",
    "http://127.0.0.1:8000",
]

CORS_ALLOW_METHODS = [
    "DELETE",
    "GET",
    "OPTIONS",
    "PATCH",
    "POST",
    "PUT",
]

CORS_ALLOW_HEADERS = [
    "accept",
    "accept-encoding",
    "authorization",
    "content-type",
    "dnt",
    "origin",
    "user-agent",
    "x-csrftoken",
    "x-requested-with",
]

# JWT Settings
SIMPLE_JWT = {
    'ACCESS_TOKEN_LIFETIME': timedelta(minutes=60),
    'REFRESH_TOKEN_LIFETIME': timedelta(days=1),
    'ROTATE_REFRESH_TOKENS': True,
    'BLACKLIST_AFTER_ROTATION': True,
}

7️⃣ API ENDPOINTS
-------------------------------------------
Authentication:
- POST /api/v1/users/register/
- POST /api/v1/users/login/
- POST /api/v1/token/refresh/

Users:
- GET  /api/v1/users/profile/
- POST /api/v1/users/update-points/
- POST /api/v1/users/update-device-token/
- POST /api/v1/users/verify-email/

Courses:
- GET  /api/v1/courses/
- GET  /api/v1/courses/<id>/
- POST /api/v1/courses/<id>/unlock/
- GET  /api/v1/courses/<id>/statistics/

Quizzes:
- GET  /api/v1/quizzes/<course_id>/
- GET  /api/v1/quizzes/<id>/
- POST /api/v1/quizzes/<id>/attempt/
- POST /api/v1/quizzes/<id>/submit/

Achievements:
- GET  /api/v1/achievements/
- GET  /api/v1/achievements/my_achievements/
- GET  /api/v1/achievements/available/

===========================================
📝 NOTES
-------------------------------------------
1. Always activate virtual environment before running commands
2. Keep requirements.txt updated when adding new packages
3. Never commit sensitive data (SECRET_KEY, passwords, etc.)
4. Use environment variables for sensitive data
5. Regular database backups recommended
6. Keep Flutter dependencies up to date
7. Test on both iOS and Android before deployment

===========================================
🔧 TROUBLESHOOTING
-------------------------------------------
1. Django Issues:
   - Migration issues:
     * Delete migrations (except __init__.py)
     * Delete db.sqlite3
     * Run makemigrations and migrate
   - CORS issues:
     * Check CORS settings
     * Verify allowed origins
   - Package conflicts:
     * Delete venv
     * Create new venv
     * Reinstall requirements

2. Flutter Issues:
   - Build errors:
     * flutter clean
     * flutter pub get
   - Hot reload not working:
     * Stop app
     * flutter run
   - Package conflicts:
     * Delete pubspec.lock
     * flutter pub get

3. Authentication Issues:
   - Clear tokens in Flutter secure storage
   - Check JWT settings in Django
   - Verify CORS headers
